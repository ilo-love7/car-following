## 0. 摘要

本项目实现了一个**开箱即用、可复现**的微观交通流跟驰建模工具箱，完成从"模型实现 → 稳态分析 → 稳定性理论 → 参数标定 → 轨迹预测 → 换道/能耗延伸"的完整闭环，并坚持**解析结论与数值仿真的双向交叉验证**：

* **7 个经典跟驰模型**统一接口：IDM、OVM、FVD、Helly(ACC)、GHR、Gipps、Newell。
* **稳态基本图**：由各家稳态关系 `s_e(v)` 解析导出流量–密度曲线与通行能力（IDM 2139 veh/h）。
* **线性稳定性**：推导平面波判据 `m = f_s − f_Δv·f_v − f_v²/2`，与环道线性化特征值符号一致率 **99.44%**。
* **串稳定性（ACC）**：给出 Helly 模型速度传递函数 `Γ(s)` 与闭式判据 `C1T² + 2C2T ≥ 2`，逐频点数值实测吻合到 3 位小数。
* **参数标定**：有界非线性最小二乘（多起点），无噪声下**精确复原** IDM 真值参数；量化了噪声–误差关系。
* **轨迹预测**：LSTM（0.195 m/s）显著优于物理模型与恒速/恒加速基线。
* **换道与能耗延伸**：MOBIL 双车道仿真；电动车能耗模型揭示"不稳定车流能耗近乎翻倍"。

## 2. 模型体系

### 2.1 统一形式与符号

跟驰模型统一写成一阶 ODE：

```
dv/dt = f(s, v, Δv)
```

* `v`：跟驰车速度；`v_lead`：前车速度；
* `s = x_lead − x − ℓ`：车头到车头净距（`ℓ` 为车长）；
* `Δv = v − v_lead`：接近速度（跟驰车更快时 `Δv > 0`，正在接近）；
* 平衡态处恒有 `f = 0`，且物理合理模型满足
  **`f_s > 0`（间隙越大越加速）、`f_v < 0`（越快越减速）、`f_Δv ≤ 0`（接近时减速）**。

离散模型（Gipps、Newell）以 `v(t+Δt)` 的显式更新给出；接口层统一暴露 `accel(s, v, Δv)` 与 `next_speed(...)`，仿真器对两类模型分别积分。

### 2.2 各模型与稳态关系

| 模型 | 加速度/速度律 | 稳态间隙 `s_e(v)` | 参考 |
|---|---|---|---|
| **IDM** | `a = a_max[1 − (v/v0)^δ − (s*/s)²]`，`s* = s0 + vT + vΔv/(2√(a_max b))` | `(s0 + vT)/√(1 − (v/v0)^δ)` | Treiber 2000 |
| **OVM** | `a = α(V(s) − v)`，`V(s)=0.5 v_max[1+tanh((s−h)/…)` | `V⁻¹(v)` | Bando 1995 |
| **FVD** | `a = α(V(s) − v) − λΔv` | `V⁻¹(v)`（同 OVM） | Jiang 2001 |
| **Helly / ACC** | `a = C1(s − s0 − Tv) − C2Δv` | `s0 + Tv` | Helly 1959 |
| **GHR (GM)** | `a = c·vᵐ·Δv / sˡ` | 无唯一稳态（退化） | Gazis 1961 |
| **Gipps** | `v(t+τ)=min(v_acc, v_safe)` | `s0 + 2vτ` | Gipps 1981 |
| **Newell** | `v = min(v_free, (s − s0)/τ)` | `s0 + vτ` | Newell 2002 |

> `equilibrium_gap(v)` 对 IDM 在 `v ≥ v0` 时返回 `inf`（无解），调用方已用 `_safe_initial_gap` 处理。

稳态关系是把**微观模型**翻译成**宏观基本图**的桥梁：

```
headway(v) = s_e(v) + ℓ
density(v) = 1000 / headway(v)         [veh/km]
flow(v)    = 3.6 · v · density(v)      [veh/h]
```

## 3. 稳定性理论

### 3.1 线性稳定性（平面波）

把每辆车写成 `v_j = v0 + u_j`、间隙 `s_j = s_e + w_j`，对一般模型 `dv/dt = f(s, v, Δv)` 在均匀平衡态线性化。利用 `ds_j/dt = v_{j-1} − v_j = −Δv_j`，代入谐波扰动 `u_j = Û e^{λt + ikj}`，得到特征方程：

```
λ² − λ[f_v + f_Δv(1 − e^{−ik})] + f_s(1 − e^{−ik}) = 0
```

长波极限 `k → 0`（`1 − e^{−ik} ≈ ik + k²/2`）下展开 `λ = λ1 k + λ2 k²`：

* `λ1 = i f_s/f_v`（纯虚 → 中性传播，不增长）；
* `Re λ2 = [−f_s²/f_v² + f_s f_Δv/f_v + f_s/2] / f_v`。

由于 `f_v < 0`，**增长（不稳定）当且仅当**

```
m = f_s − f_Δv·f_v − f_v²/2  >  0
```

即 **稳定 ⟺ `m < 0`**。`m` 只依赖平衡点的三个偏导，与波长无关，是长波（拥堵）不稳定性的判据。

**数值验证（case 2）**：在 `(T, v)` 的 40×40 网格上，逐点比较解析判据符号与 `N=120` 环道线性化矩阵的最大特征值实部符号，**一致率 99.44%**；解析判定为不稳定的网格占比 21.4%，与"高密度 / 短车头时距更容易不稳定"的直觉一致。

### 3.2 环道离散特征值

环道把无限车流截断成 `N` 辆车的周期边界，均匀态的线性化是一个 `N×N` Jacobian。其 `N` 个特征值对应 `N` 个模态（含一个平移中性模 `λ = 0`），定义

```
max_ring_growth = max Re λ  （排除中性模）
```

`max_ring_growth > 0` 对应扰动增长。它与 3.1 的解析判据在大量参数点上符号一致，且能给出**有限波长下的最快增长率**——这正是 case 3A 用来预测速度方差指数增长/衰减速率的量。

### 3.3 串稳定性（Helly / ACC）

串稳定性关注"扰动沿车队**向后传播**是否被放大"（而非仅仅是否增长）。对 Helly 模型线性化并取拉普拉斯变换，得到前车速度到跟驰车速度的传递函数

```
Γ(s) = (C2 s + C1) / (s² + (C1 T + C2) s + C1)
```

串稳定 ⟺ `|Γ(iω)| ≤ 1, ∀ω`。展开可得**闭式判据**

```
C1·T² + 2·C2·T  ≥  2
```

**数值验证（case 3B）**：对稳定组 `(C1,C2,T)=(0.4,0.9,1.2)` 与不稳定组 `(0.2,0.2,1.2)`，在 10 个频点上用正弦前车激励**实测**放大率，与解析 `|Γ(iω)|` 逐点吻合（稳定组 max 0.998 vs 0.998；不稳定组 1.229 vs 1.229）。

## 4. 数值方法

### 4.1 连续模型：RK4 + 自适应子步

`simulate_following` / `simulate_ring` 用四阶 Runge–Kutta 积分。为避免"前车急刹时粗采样导致穿透"，内部对 `dt` 做**子步细分（≤ 0.02 s）**，对外仍按用户 `dt` 输出，保证结果与采样步长弱相关。

### 4.2 离散模型：Gipps / Newell

按模型自带反应时间 `τ` 显式推进（`next_speed`），与连续模型的积分器分离但共用同一仿真外壳。

### 4.3 单位与约定

* 全部内部量用 SI（m, m/s, s）；NGSIM 适配器负责 ft→m 换算。
* 环道"前车"索引为 `j = (i+1) mod N`（沿行驶方向位置递增），避免绕行方向搞反导致伪解耦。

### 5.2 Case 2 — 线性稳定性判据的网格验证

* 网格：`T ∈ [0.4, 2.0]`、`v ∈ [2, 30]`，40×40；
* 解析不稳定占比 **21.4%**；
* **解析 vs 环道特征值符号一致率 99.44%**；
* 各模型稳定边界速度：IDM 14.66 m/s、OVM 10.81 m/s；FVD 与 Helly 在网格内**始终稳定**（FVD 的 `−λΔv` 项、Helly 的 `−C2Δv` 项显著改善稳定性）。
* IDM 稳定性裕度 `m`：`v=10→+0.0165`（不稳定）、`v=15→−0.0006`、`v=20→−0.0226`、`v=25→−0.0412`、`v=28→−0.0382`。

> 结论：解析判据 `m` 不仅"对/错"分得清，而且能刻画"离稳定边界多远"，与数值完全一致。

### 5.3 Case 3A — 环道动力学（阻尼 vs 增长）

40 辆车、`L=5 m`、环道长度按稳态关系配置 `ring_length_for(v_eq, N, m, L)`，初始加 3 cm/8 cm 量级小扰动：

| 组 | `T` (s) | `v_eq` (m/s) | 预测增长 (1/s) | 拟合增长 (1/s) | σ 初 → 末 (m/s) | 判定 |
|---|---|---|---|---|---|---|
| 稳定 | 1.8 | 18 | −0.0049 | **−0.0206** | 0.072 → 0.005 | 速度方差**衰减** ✅ |
| 不稳定 | 0.4 | 6 | +0.0748 | **+0.0641** | 0.074 → 3.22 | 速度方差**增长 43×** ✅ |

要点：短车头时距 + 低速（高密度）组扰动成长并**饱和为走走停停**（σ 增至 3.2 m/s），长车头时距组迅速回到均匀流。预测与拟合的**符号一致、量级同阶**；差异来自线性预测只保留最长波模态、而实测含非线性饱和。

### 5.4 Case 3B — 串稳定性（解析 vs 数值）

| 组 | `(C1, C2, T)` | 闭式判据满足？ | max\|Γ\| 解析 | max\|Γ\| 数值 |

### 5.6 Case 5 — 短时轨迹预测

设置：历史 4 s（20 步）、预测 10 s（50 步）、`dt = 0.2 s`；训练/测试按**不同随机种子的车队**划分（288 / 72 窗口），前车未来视为已知。

| 预测器 | RMSE_v (m/s) | RMSE_gap (m) |
|---|---|---|
| 恒速 CV | 0.814 | 3.428 |
| 恒加速 CA | 1.127 | 3.314 |
| 物理 IDM | 1.125 | 5.380 |
| **LSTM** | **0.195** | **0.803** |

要点：在学习数据充足时，LSTM 把速度 RMSE 降到物理基线的约 1/6；但物理 IDM 在未精调（用平均参数）时不如恒速基线——印证"物理模型价值依赖参数标定质量"，为 case 4 的标定意义提供注脚。

### 5.7 Case 6 — MOBIL 换道（双车道微仿真）

24 辆车、80 s、`dt = 0.1 s`；MOBIL 参数 `politeness=0.2, threshold=0.2, b_safe=3.0, bias_right=0.3`，并施加**最小停留时间 5 s** 抑制抖动式换道。

结果：**19 次换道**；平均车速 **23.19 m/s**、最高 26.92 m/s；速度区间 [13.7, 26.9] m/s。加入停留约束前为 77 次（明显抖动），约束后降至 19 次，换道行为更贴近实际。

### 5.8 Case 7 — 电动车能耗

纵向能耗模型：`P_batt = (F_drag + F_roll + F_inertia + F_grade)·v / η_drive + P_aux`，制动时按 `η_regen` 回收。

**(a) 三种驾驶风格**（同一 60 s 城市/高速混合轨迹的不同"激进度"）：

| 风格 | 距离 (km) | 能耗 (kWh) | 百公里能耗 (kWh/100km) |
|---|---|---|---|
| 经济 | 0.96 | 0.090 | **9.32** |
| 常规 | 1.05 | 0.175 | **16.71** |
| 激进 | 0.96 | 0.322 | **33.46** |

**(b) 恒速能耗曲线**：呈 U 形（气动阻力随 `v²`、单位距离时间随 `1/v`），最小值出现在 ~40–50 km/h 区间。

**(c) 车流稳定性 → 能耗（同一目标车速的对照实验）**：

| 车流 | 平均车速 (m/s) | 速度标准差 (m/s) | 百公里能耗 |
|---|---|---|---|
| 平稳流（T=1.8） | 12.0 | 0.00 | **7.32** |
| 走走停停（T=0.5） | 10.0 | 3.33 | **14.09** |

> 结论：**仅因车头时距更短导致的不稳定**，车流演化出走走停停波，能耗从 7.32 升到 14.09 kWh/100km（**+93%**）。这为"交通流稳定性 → 能耗/排放"提供了定量链路。

### 5.9 Case 8 — NGSIM 适配器

**链路**：NGSIM 文本（美国惯用单位、10 Hz）→ `load_ngsim` 自动分隔符识别 + ft→m 换算 → `extract_following_events` 抽取"持续 ≥20 s 的同前车跟驰事件" → `calibrate_following` 标定。

由于真实 NGSIM 文件较大且需从 data.gov 下载，**仓库不附带**；`case8` 默认用一个**合成的 NGSIM 格式夹具**（由已知 IDM 车队转换而来）验证整条链路：

* 夹具 4 车、80 s、10 Hz，共 3204 行；
* 抽取到 2 个合法跟驰事件；
* 事件 0：跟驰车 2 ← 前车 1，间隙 21.8–49.3 m，速度 ~22 m/s；
* 标定 RMSE_gap = **0.000 m**、RMSE_v = **0.000 m/s**（在已知真值上精确复原 → 换算与抽取无系统性偏差）。

将真实文件放入 `data/ngsim/` 后，脚本自动切换到真实数据并跳过真值比对。

## 8. 局限与展望

1. **线性稳定性为长波判据**：case 3A 中预测与拟合的**数值**差异源于线性理论不含非线性饱和与有限波长模式，后续可用弱非线性分析（如 KdV / mKdV）解释走走停停的孤立波振幅。
2. **LSTM 未做严格泛化测试**：目前仅在同一生成分布内留出测试；真实数据上需重做域偏移实验。
3. **MOBIL 换道为运动学插入**：未建模换道轨迹（横向动力学）与多车道协同。
4. **能耗模型为纵向准静态**：未含空调/温度/坡道时空变化与电池内阻损耗（可与本系列 P4 电池建模衔接）。
5. **NGSIM 未内置真实数据**：受数据体积与许可限制；接口已就绪。
